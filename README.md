# Charis Moutafidis · Χάρης Μουταφίδης

**Software engineer, founder of Fiji Solutions and Peak Code**

Charis Moutafidis is a software engineer with more than ten years of experience. He founded Fiji Solutions in Thessaloniki and Peak Code Consulting in Aarau. Both companies build custom software for businesses: web and mobile apps, process automation, AI agents and websites. Fiji Solutions works with businesses in Greece and abroad and is a Snowflake AI Data Cloud Select Partner. Peak Code Consulting GmbH builds custom software for companies in Switzerland, and its offers include Camunda 7 migration. He is the managing director of Peak Code Consulting GmbH. At Fiji Solutions, clients talk directly to the engineer who builds their software.
